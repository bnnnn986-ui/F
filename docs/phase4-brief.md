## Track A — game flow (quiz-race + room end-game)
1. **Host control bar** during any game (room shell, top-right, compact):
   Pause/Resume, Skip, "จบเกม" → confirm modal "จบภารกิจนี้แล้วกลับโรงเตี๊ยม?"
   with "ไปที่โพเดียมเลย" (tally scores so far) / "กลับโรงเตี๊ยมโดยไม่บันทึกคะแนน" / "ยกเลิก".
2. **Auto-play** (Kahoot "Autoplay" is opt-in; Wayground is instructor-paced):
   setting "เดินเกมอัตโนมัติ" default **OFF** when host presents (wide
   viewport, host-plays off), default **ON** when "โฮสต์ร่วมเล่นด้วย" is on;
   explicit host choice persisted and wins. Per question: read phase
   (question only, answers hidden, 3 s, also on phones) → answering → reveal
   → leaderboard → next. Auto mode: reveal 5 s, leaderboard 5 s, "ถัดไป"
   shows a draining ring and can be pressed early; Pause freezes timers
   (absolute timestamps, shift on resume; reload-safe). Questions always end
   when the timer hits 0 or everyone answered.
3. **Answer summary on reveal**: host = Kahoot-style vertical bars per option
   (colour + shape, count and % above, correct one marked with the check
   icon, avatar stack of who chose it, max 6 + "+N"). Phone = your answer,
   correct answer, "คนส่วนใหญ่ตอบ … (60%)".
